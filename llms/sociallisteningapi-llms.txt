# sociallisteningapi

sociallisteningapi searches public posts, videos, profiles, forum discussions, and Google results through one API key and a normalized response structure.

## Core Capabilities
- Search public posts and videos from LinkedIn, X, Reddit, Facebook, Hacker News, TikTok, and YouTube.
- Search public Reddit comments by keyword.
- Search public Instagram users, hashtags, and places, and retrieve public profiles.
- Search posts in one public Discourse forum by URL and keyword.
- Retrieve Google results through the same API key.
- Use a normalized response structure across supported sources.
- Buy one-time credit packs that do not expire.
- Read the public endpoint documentation and OpenAPI document.
